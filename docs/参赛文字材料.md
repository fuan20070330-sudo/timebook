## 一、作品名称

**时间之书：二十四节气的天文与物候科普**

可选短名称：**时间之书**

## 二、作品简介

《时间之书》是一款面向公众和青少年学习传统文化与天文知识的交互式科普 Web 应用。作品以二十四节气为时间线索，把太阳视黄经、太阳直射点、七十二候、农事活动、生活习俗与古典诗词组织在同一套可探索的数字叙事中。用户可以通过二十四节气圆盘了解每个节气在黄道上的位置，查看每个节气对应的三候和科学解释；在七十二候图鉴中按季节筛选物候，并通过动态知识测验检验理解。作品还提供观察手账和节气卡导出功能，用户可以勾选自己观察到的物候、记录当天的风向、天空和植物变化，并生成带有节气、天文数据、诗句和个人观察的 PNG 作品。

作品采用 HTML5、CSS3、原生 JavaScript、SVG 和 Canvas 实现，依据太阳视黄经近似算法自动定位当前节气并计算下一交节时刻。应用无需登录、后端服务、专用硬件或外部 AI 接口，支持桌面端和移动端浏览器，可作为课堂辅助、家庭自然教育或个人节气观察工具使用。作品希望解决传统节气知识“看得见但不易理解、记得住但缺少观察”的问题，让用户从被动阅读走向主动观察、解释和记录。

## 三、创意来源

二十四节气是中国古代先民通过观察太阳周年运动、气候变化和物候规律形成的时间知识体系，2016 年被列入联合国教科文组织人类非物质文化遗产代表作名录。它同时包含天文、农业、气候、民俗和文学内容，但在日常传播中，节气常被简化为日历上的名称、节日海报或养生口号，公众知道“有二十四个节气”，却不一定理解每个节气为什么出现、太阳走到了哪里、物候发生了什么变化。

作品由此提出一个设计思路：不只做“节气百科”，而是把节气还原为一套可以观察和验证的时间方法。用户先通过节令盘看到太阳黄经与四季的关系，再用七十二候把抽象的节气落到具体物候，通过测验检验“能否解释”，最后用手账把知识带回真实生活。作品希望用数字交互降低传统文化与天文知识的理解门槛，让二十四节气从静态记忆材料变成可以持续使用的观察工具。

Windows 10/11、macOS、Android、iOS 等常见操作系统；Chrome、Edge、Firefox、Safari 最新版本；支持桌面端、平板和移动端浏览器。作品为纯前端 Web 应用，基于 HTML5、CSS3、JavaScript、SVG 和 Canvas 实现，使用 localStorage 保存本地观察记录。无需安装客户端、无需登录、无需后端服务、无需专用硬件或独立显卡，也不依赖外部 AI API。可在线访问，也可直接打开本地版本运行；在线版本需要网络，离线版本无需网络。

## 五、主要创新点

1. **把节气知识组织为学习闭环**：不是单纯罗列 24 个节气，而是按照“观时—识候—解释—记录”的顺序设计交互，形成可学习、可练习、可迁移的完整路径。
2. **把天文计算转化为可视化体验**：根据太阳视黄经近似算法自动判断当前节气、下一交节时刻和太阳直射点纬度，让用户直接看到抽象天文参数与节气的关系。
3. **用七十二候连接知识与真实观察**：72 条物候既可按季节浏览，也可通过观察手账转化为个人的自然记录，避免知识停留在屏幕阅读。
4. **生成个人学习成果**：用户可将所选节气、三候、天文数据和自己的观察记录导出为 1200×1600 的 PNG 节气卡，便于课堂展示、社群分享和成果留存。
5. **低依赖、可离线、易传播**：纯前端实现，无登录和后端，不依赖外部图片或 AI 接口，普通浏览器即可运行，适合学校、家庭和科普场馆使用。

## 六、建议使用流程

1. 打开作品，查看首页自动定位的当前节气；
2. 转动节令盘，了解节气与太阳黄经的对应关系；
3. 选择任意节气，阅读三候、科学解释、农事和生活建议；
4. 进入七十二候图鉴，按季节筛选并寻找自己熟悉的物候；
5. 完成 8 道知识测验，检查对天文位置和物候关系的理解；
6. 在观察手账中勾选当天看到的物候，写下现场记录；
7. 导出节气卡，作为个人观察成果或课堂分享材料。
