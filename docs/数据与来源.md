# 数据与来源说明

## 1. 节气与七十二候

- 二十四节气名称、顺序与七十二候名称按公开通行的中国传统历法资料整理。
- 每个节气的太阳黄经目标值按节气顺序设置：立春 315°，此后每节气增加 15°，春分为 0°，夏至为 90°，秋分为 180°，冬至为 270°。
- 节气介绍、农事、生活建议与物候解释为面向科普阅读的整理性文字，不替代专业农技、医疗或气象建议。

## 2. 天文计算

`js/app.js` 中的太阳视黄经采用常用的低阶天文近似算法：

1. 计算儒略日与 J2000.0 起的儒略世纪数；
2. 计算太阳几何平黄经、平近点角和中心差；
3. 加入章动与光行差的一阶近似修正；
4. 得到太阳视黄经 λ；
5. 根据 λ 与各节气目标黄经的差值判断当前节气；
6. 在目标黄经前后进行二分搜索，估算交节时刻。

页面显示的交节日期与倒计时为计算结果，用于交互与科普演示。正式历算、交节日期和节气时刻应以中国科学院紫金山天文台等权威机构发布的历书为准。

## 3. 诗句

页面中的古典诗句均来自公版古典文学作品，标注作者与篇名。正式提交前应逐条核对版本、作者归属和断句。

## 4. 视觉与素材

当前版本未使用第三方图片、插画、字体文件、音效或视频。所有视觉元素由以下方式原创生成：

- CSS 渐变、圆环、网格和纹理；
- 内联 SVG 图标与节气盘；
- JavaScript 动态 DOM；
- Canvas 生成节气卡。

## 5. 参考方向

- 联合国教科文组织：The Twenty-Four Solar Terms, knowledge in China of time and practices developed through observation of the sun's annual motion（2016 年列入人类非物质文化遗产代表作名录）。
- 中国科学院紫金山天文台发布的历算与节气资料。
- 中国农业博物馆及公开出版的中国传统节气、农事与物候资料。
- 公版古典诗词文献。
