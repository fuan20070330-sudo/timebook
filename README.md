# 时间之书：二十四节气的天文与物候科普

**响应式 Web 应用 / PWA**

- 竞赛分类：自主命题——智慧教育与科普创作
- 作品形态：纯前端响应式 Web 应用 / PWA
- 运行方式：普通电脑或手机浏览器；无需登录、后端、专用硬件或外部 AI 接口
- 核心学习闭环：**观时 → 识候 → 解释 → 记录**

## 作品定位

《时间之书》把二十四节气从静态日历转化为一套可观察、可解释、可记录的时间知识系统。用户先通过节令盘观察太阳黄经与四季变化，再进入七十二候理解物候线索，随后用知识测验检验理解，最后在观察手账中记录真实世界的风、云、植物与温度。

## 当前功能

1. **二十四节气节令盘**
   - 24 个节气按立春起顺时针排列；
   - 点击查看太阳黄经、太阳直射点、三候、农事、生活建议和节气诗句；
   - 根据当前日期自动定位真实节气。

2. **太阳视黄经计算**
   - 使用太阳视黄经近似算法判断当前节气与下一交节时刻；
   - 同步显示太阳直射点纬度；
   - 页面每 60 秒刷新一次。

3. **七十二候图鉴**
   - 24 节气 × 3 候 = 72 条物候；
   - 首屏显示 4 条，向下滚动每次继续加载 4 条；
   - 支持全部、春、夏、秋、冬分类筛选；
   - 搜索框只匹配节气名称，如“立春”“夏至”；
   - 点击任意一候返回所属节气。

4. **知识实验室**
   - 动态生成 8 道节气、天文、物候与文化题；
   - 按天文、物候、文化三个维度统计掌握度；
   - 保存最近学习画像，并根据薄弱维度给出复习建议；
   - 即时反馈与解释，可反复练习。
   - 提供 7 张可展开的“节气科学辨析”卡，区分历法、天文、物候与古代观察。

5. **观察手账**
   - 勾选观察到的物候并填写现场记录；
   - 使用 localStorage 保存在当前浏览器；
   - 自动生成 1200 × 1600 的 PNG 节气卡。

6. **科学性与响应式**
   - 七十二候区域明确标注古代物候记录的性质与使用边界；
   - 提供节气、天文算法、诗句和视觉素材的来源说明面板；
   - 桌面端、平板和手机自适应；
   - 提供 PWA manifest 与 service worker；
   - 页面代码不依赖任何第三方图片或在线 API。

## 本地运行

直接双击 `index.html` 可使用全部核心功能。若需要验证 PWA 与 service worker，请在目录中启动静态服务器：

```powershell
python -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 科学说明

节气交节时刻由前端根据太阳视黄经近似计算，用于交互展示与科普说明；正式历算以中国科学院紫金山天文台等权威机构发布的数据为准。传统节气、七十二候与诗句仅作为公开文化知识整理，不替代专业天文年历。
